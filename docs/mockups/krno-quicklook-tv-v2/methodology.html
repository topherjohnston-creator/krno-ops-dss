Purpose

This quicklook page is a partner-facing situational awareness display for Reno-Tahoe International Airport ground operations. It is designed to summarize operational weather risk quickly, not replace official forecasts, warnings, or local decision procedures.

Risk Categories

Displayed risk categories are locally configured for decision support: Little to None, Minor, Moderate, Major, and Extreme. These categories are mapped from available forecast probabilities, thresholds, and operational impacts.

Hazards

The dashboard supports wind, visibility, snow, rain, lightning, flash freeze, temperature, and freezing rain. The quicklook page emphasizes the highest operational concerns while keeping lower-risk hazards visible.

Data Inputs

Values are based on available model guidance, generated JSON products, current KRNO observations, NWS alerts, radar imagery, and lightning proximity data where available. If a field is missing, stale, or unavailable, the dashboard should not imply all-clear conditions.

Stale Or Missing Data

Stale observations and missing lightning/radar data are displayed as degraded data states. Stale or unavailable data should not be interpreted as safe, all clear, or operationally current.
